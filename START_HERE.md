# Start here

1. Read `CLAUDE_BUILD_GUIDE.md` completely.
2. Install dependencies: `pip install -e ".[dev]"`.
3. Run tests: `pytest`.
4. Initialize local data: `flightzero init`.
5. Try `flightzero book FLIGHT-001 A0` and `flightzero check`.

When merging into the older airline repository, ask Claude to inspect and reconcile the existing code before copying files over. Do not overwrite working code blindly.
