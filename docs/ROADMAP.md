# Roadmap

## Stage 1 — Reliable local core
Typed models, booking/cancellation, safe JSON writes, invariant checker, unit/integration/concurrency tests.

## Stage 2 — Concurrency laboratory
Configurable worker counts, deterministic scenarios, experiment IDs, metrics, reproducible reports.

## Stage 3 — Fault injection and recovery
Controlled crash points, restart tests, recovery journal, reconciliation, operator approval, verification.

## Stage 4 — Distributed infrastructure
PostgreSQL adapter, database constraints, transaction-isolation tests, optional Redis seat holds, multi-instance tests.

## Stage 5 — AI incident investigator
Redacted incident bundles, evidence-linked hypotheses, suggested diagnostics and regression tests, human approval.

## Stage 6 — Observability
Experiment dashboard, failure timelines, contention visualization, measured before/after comparisons.
